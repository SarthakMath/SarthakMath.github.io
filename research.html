Research

I work on finite element methods for convection–diffusion–reaction equations. When convection dominates, standard Galerkin solutions oscillate near layers. Algebraic flux correction removes the oscillations by modifying the algebraic system directly, and I study how to design and analyse the limiters that make this work.

Interests

Numerical analysis of partial differential equations, applied mathematics, and physics-informed neural networks.

Preprint

Bilinearity preserving algebraic flux correction

Sarthak Sourav Dash and Abhinav Jha. arXiv:2609.16830. MSC 65N30, 65N12, 65N15.

Flux-corrected schemes are usually built to be linearity preserving: the limiter switches off when the discrete solution is affine, so no artificial diffusion is added where none is needed. We ask for the same on bilinear solutions. We characterise the mesh patches where this is possible by a convex hull condition on lifted neighbours, give a sharp explicit limiter parameter on axis-aligned patches, and confirm the theory with numerical experiments.
